# Gabriel Sandim

Full stack engineer from Brazil. I build web and mobile products in TypeScript, and most of my work now is LLM engineering: the APIs that call the models, what they cost and how we measure them.

## What I'm building

- **[Obra Nova](https://www.obranova.com.br)**: construction management app with a WhatsApp assistant that writes the daily site report from text and voice notes. Evals gate every release ([case study](https://www.gbstec.dev.br/cases/obra-nova)).
- **[task-funnel](https://github.com/gabrielbsandim/task-funnel)**: Claude Code plugin that takes an issue to a draft PR and stops for approval before risky code. On a risky money fix it took the score from 0.08 to 1.00 ([case study](https://www.gbstec.dev.br/cases/task-funnel)).
- **[Cashdeck](https://github.com/gabrielbsandim/cashdeck)**: self-hosted household finance for Brazil, with Open Finance sync and an AI chat.
- **[autocad-mcp](https://github.com/gabrielbsandim/autocad-mcp)**: MCP server that lets Claude query, draw and export AutoCAD drawings.
- **[Lifedeck](https://github.com/gabrielbsandim/lifedeck)**: shareable, multilingual to-do platform with a white-label REST API.

**Stack:** TypeScript, React, Next.js, Node.js, React Native, Flutter, Postgres.
